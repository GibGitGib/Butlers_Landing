Cookie & Browser Storage Policy

This page explains the small amount of browser storage used by the Business Butlers site and its assessment assistant.

What we store

  • Theme preference: local storage remembers light or dark mode.
  • Chat session: session storage keeps a random session ID, the answers you select, the current assessment step, and the chat transcript so a refresh does not erase your work.
  • Trigger state: session storage remembers whether the assistant has already opened automatically in this browser tab.

Session storage is cleared when the browser tab/session ends. We do not use advertising cookies.

Engagement analytics

From page load, we record pseudonymous events such as sections reached, dwell thresholds, scroll depth, assistant opens, and conversion steps. These events use the random session ID and exclude raw chat text, names, email addresses, and URL query strings.

If you voluntarily submit an assessment or email address, the lead record carries the same session ID so we can understand which site journey produced the inquiry. Detailed analytics are retained for 90 days.

How to control storage

You can clear site data through your browser settings or close the browser session to remove session storage. Blocking browser storage may cause the assessment to restart after a refresh.

For the complete description of processing, service providers, retention, and your rights, read the Privacy Policy.
